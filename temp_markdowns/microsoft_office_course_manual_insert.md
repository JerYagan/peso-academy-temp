## Module 1: Microsoft Word Essentials for Professional Documents

### Module Description

This module introduces the basic tools and habits needed to create clear, polished, and professional documents in Microsoft Word. Learners will understand how to structure a document, apply consistent formatting, and collaborate with reviewers using built-in features.

### Learning Outcomes

- Create a clean and readable document structure
- Use headings, styles, lists, and tables properly
- Apply formatting that improves clarity instead of distracting the reader
- Use review features such as comments and Track Changes

### Text Block 1: Start with a clean document structure

Microsoft Word is most useful when a document is easy to read, edit, and share. Begin by choosing the correct page setup, using a clear title, and organizing the page with headings instead of manually enlarging text. This makes long documents easier to navigate and update.

Use built-in styles for headings, body text, and lists so formatting stays consistent across the whole file. Consistency matters in resumes, letters, reports, meeting notes, and any document that other people need to review.

### Text Block 2: Format for clarity, not decoration

Good formatting improves readability. Choose one or two fonts, keep spacing consistent, and use bullets or numbered lists when presenting steps or grouped ideas. Avoid using many font colors, oversized text, or unnecessary effects because they make the document harder to scan.

Headers, footers, page numbers, and tables are practical tools for formal documents. When information must be reused later, tables and properly aligned paragraphs are easier to maintain than text arranged with spaces or repeated tab presses.

## Module 2: Microsoft Excel Essentials for Worksheets and Calculations

### Module Description

This module introduces learners to worksheet organization, structured data entry, and the basic formulas used in Excel. It focuses on spreadsheet habits that support accurate calculations and easier reporting.

### Learning Outcomes

- Organize worksheet data in a structured format
- Understand rows, columns, headers, and consistent data types
- Use basic Excel formulas and functions for common tasks
- Distinguish between relative and absolute references

### Text Block 1: Keep worksheet data structured

In Excel, reliable analysis starts with clean data entry. Use one header row, keep each column focused on one kind of value, and avoid leaving random blank rows inside the dataset. A structured table is easier to sort, filter, total, and chart.

When the worksheet represents attendance, inventory, expenses, or performance tracking, each row should represent one record and each column should represent one field such as date, name, amount, or status.

### Text Block 2: Use formulas to reduce manual work

Excel formulas save time and reduce repeated calculations. Start with basic operators like addition, subtraction, multiplication, and division, then move to functions such as SUM, AVERAGE, MIN, MAX, and COUNT. These functions are useful for reports, budgets, and simple monitoring dashboards.

Cell references matter. Relative references change when a formula is copied, while absolute references stay fixed. Understanding that difference helps prevent errors when filling formulas down a column.

### Quiz 1

**Question:** Which type of Excel reference stays fixed when you copy a formula to other cells?

- A. Absolute reference
- B. Relative reference
- C. Filtered reference
- D. Hidden reference

**Correct Answer:** A. Absolute reference  
**Explanation:** Absolute references lock a row, column, or both so the formula keeps pointing at the same cell.

### Quiz 2

**Question:** Which function should you use if you want to total a list of numeric values in a column?

- A. SUM
- B. UPPER
- C. LEFT
- D. TRIM

**Correct Answer:** A. SUM  
**Explanation:** SUM adds numeric values and is one of the most common worksheet functions.

## Module 3: Microsoft PowerPoint Essentials for Clear Presentations

### Module Description

This module helps learners create presentations that are readable, organized, and useful in real reporting situations. It introduces slide planning, good visual design, and consistency across a presentation deck.

### Learning Outcomes

- Organize presentation content into a clear sequence
- Design readable slides with strong visual hierarchy
- Use layout and consistency to improve professionalism
- Understand how Slide Master supports presentation formatting

### Text Block 1: Build slides around one idea at a time

A strong presentation helps the audience understand your message quickly. Each slide should focus on one main point supported by a short title and only the most important details. Overcrowded slides force people to read instead of listen.

Use simple slide order: introduce the topic, explain the key points, show an example or evidence, and end with a clear summary or next step. This structure works for class reports, project updates, and office briefings.

### Text Block 2: Design for readability and consistency

Readable presentations use high contrast, large enough text, and limited on-screen clutter. Keep slide backgrounds simple and use images, icons, or charts only when they add meaning. Repeating the same colors and layouts across slides makes the presentation look more professional.

Slide Master is useful when you want the same font, logo placement, or footer structure across many slides. It saves time and reduces formatting mistakes in longer presentations.

### Questions

**1. Which Microsoft Word feature is most appropriate when you need heading formatting to stay consistent across a multi-page report?**

- A. Styles
- B. Text boxes
- C. WordArt
- D. Page Color

**Correct Answer:** A. Styles  
**Explanation:** Styles help keep headings consistent and make navigation easier in long documents.

**2. True or false: In Word, Track Changes is useful when a reviewer needs to suggest edits that can be accepted or rejected later.**

**Correct Answer:** True  
**Explanation:** Track Changes preserves review visibility instead of silently overwriting the original text.

**3. In Excel, what is the best reason to keep one header row and one type of data per column?**

- A. It makes sorting, filtering, and formulas more reliable
- B. It prevents users from entering formulas
- C. It automatically creates a presentation
- D. It removes the need for labels

**Correct Answer:** A. It makes sorting, filtering, and formulas more reliable  
**Explanation:** Structured data is easier for Excel tools to interpret correctly.

**4. Which Excel function should a learner use to total values from several cells?**

- A. SUM
- B. TRIM
- C. UPPER
- D. LEFT

**Correct Answer:** A. SUM  
**Explanation:** SUM is the standard function for adding numeric values.

**5. True or false: An absolute reference in Excel stays fixed when a formula is copied to another cell.**

**Correct Answer:** True  
**Explanation:** Absolute references lock the referenced row, column, or both.

**6. Which PowerPoint practice best improves readability during a live presentation?**

- A. Use one main idea per slide with concise text
- B. Fill each slide with full paragraphs
- C. Use many font styles on every slide
- D. Add animations to every object automatically

**Correct Answer:** A. Use one main idea per slide with concise text  
**Explanation:** Slides should support the speaker, not replace them with dense reading material.

**7. What is the main benefit of Slide Master in PowerPoint?**

- A. It keeps layouts and formatting consistent across slides
- B. It checks spreadsheet formulas
- C. It stores email messages
- D. It converts slides into database tables

**Correct Answer:** A. It keeps layouts and formatting consistent across slides  
**Explanation:** Slide Master is designed to control repeated design elements across a presentation.

**8. A staff member needs to draft a formal letter, compute monthly totals, and present results in a meeting. Which Office tool set is the best match?**

- A. Word for the letter, Excel for totals, and PowerPoint for the presentation
- B. Excel for the letter, Word for totals, and PowerPoint only for storage
- C. PowerPoint for the letter, Excel for presenting, and Word for formulas
- D. Only Word for all three tasks because the apps have the same purpose

**Correct Answer:** A. Word for the letter, Excel for totals, and PowerPoint for the presentation  
**Explanation:** Each app serves a different productivity role: documents, calculations, and presentations.
